# 把论文 PDF 变成可用资料

[返回首页](../README.md#科研专题)

从 PDF 到可检索文本、公式和参考文献。按材料类型选工具，并检查提取结果。

适合：需要整理全文、搭建论文库或抽取文献信息的研究者。

预期产出：结构化文本、公式、表格或参考文献数据。

## 操作路线

1. **挑一份有代表性的样本**：先选包含双栏、公式、表格的几页材料，明确是扫描件还是有文字层的 PDF。保留原件用于核对。
2. **按输出目的选择**：需要全文和版面可看 MinerU、Docling；重点提取论文元数据与引文可看 GROBID；需要坐标信息可看 OpenDataLoader。
3. **核对后再批量**：逐项检查阅读顺序、公式符号、表格单位和参考文献。小样本达到你的要求后，再处理整批材料。

## 按需求选工具

以下是基于目录信息整理的操作建议，具体配置以原项目文档为准。

### [MinerU](https://github.com/opendatalab/MinerU)

类型：工具连接服务（MCP）。

- 适合：全文包含双栏、公式或扫描页面，希望转为结构化内容。
- 第一步：按项目文档选择运行方式，先转换一份小 PDF，保留生成文本和原页截图。
- 检查：对照公式上下标、跨页表格和双栏阅读顺序。
- 使用条件与局限：模型和运行方式会影响资源需求及效果；复杂版面仍需人工复核。

### [docling-mcp](https://github.com/docling-project/docling-mcp)

类型：工具连接服务（MCP）。

- 适合：已使用支持 MCP 的客户端，希望把文档转换接入现有工作流。
- 第一步：先配置 Docling MCP，再让客户端转换一份示例文档并检查可用输出。
- 检查：检查标题层级、表格结构以及本地文件路径是否正确。
- 使用条件与局限：需要配置 MCP 和相应运行环境，初次使用会有安装成本。

### [grobid](https://github.com/grobidOrg/grobid)

类型：工具。

- 适合：主要需要论文作者、章节、参考文献等结构化信息。
- 第一步：根据官方文档运行服务，使用一篇论文测试全文或参考文献提取。
- 检查：逐条对照作者、年份、题名、DOI 和引文对应关系。
- 使用条件与局限：侧重学术文献结构；图像和复杂公式的处理需结合其他工具。

### [opendataloader-pdf](https://github.com/opendataloader-project/opendataloader-pdf)

类型：工具。

- 适合：后续需要追溯文字、表格所在的版面位置。
- 第一步：按项目文档解析小样本，查看结构化输出及坐标信息。
- 检查：检查坐标对应的原页、表格边界和文本顺序。
- 使用条件与局限：不同 PDF 的结构差异较大，要用自己的材料评估结果。
