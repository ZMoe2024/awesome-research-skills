# 让数据分析有据可查

[返回首页](../README.md#科研专题)

从整理变量到选择统计方法，再到保存分析过程。按你的操作习惯挑选入口。

适合：有实验或调查数据，需要完成统计、探索和可视化的研究者。

预期产出：分析设置、结果表、图表与可追溯记录。

## 操作路线

1. **整理数据与研究问题**：保留原始数据，注明变量类型、单位、缺失值和分组规则。先写出想回答的问题，再选方法。
2. **选择操作方式**：偏好图形界面可看 jamovi 或 JASP；需要可视化工作流可看 Orange；已有 R 与 MCP 环境可看 r-stats-mcp。
3. **保存设置并复核**：检查方法假设、样本量和异常值处理；同时报告效应量及不确定性。保存文件与设置，确认结果可重现。

## 按需求选工具

以下是基于目录信息整理的操作建议，具体配置以原项目文档为准。

### [jamovi](https://github.com/jamovi/jamovi)

类型：工具。

- 适合：希望用图形界面完成常见统计分析，并查看 R 语法。
- 第一步：导入一份脱敏 CSV，核对变量类型后，先做描述统计和数据分布检查。
- 检查：核对缺失值、分组、变量尺度和选择的检验设置。
- 使用条件与局限：图形界面降低操作门槛，统计方法的适用性仍需要你判断。

### [JASP](https://github.com/jasp-stats/jasp-desktop)

类型：工具。

- 适合：希望通过图形界面使用频率学派或贝叶斯统计方法。
- 第一步：导入样本数据，按研究问题选择分析，并保存项目文件。
- 检查：确认模型假设、先验设置（如适用）和结果解释。
- 使用条件与局限：不同分析的解释方式不同，不宜只根据显著性判断结论。

### [Orange Data Mining](https://github.com/biolab/orange3)

类型：工具。

- 适合：希望通过连接组件探索数据或搭建机器学习流程。
- 第一步：先连接数据导入、查看和可视化组件，再逐步加入模型与评估。
- 检查：核对训练与测试划分，避免目标信息泄漏。
- 使用条件与局限：工作流可视化不意味着评估自动可靠，需要正确设计验证方案。

### [r-stats-mcp](https://github.com/Ian3738/r-stats-mcp)

类型：工具连接服务（MCP）。

- 适合：已配置 R，希望从支持 MCP 的客户端调用统计分析。
- 第一步：按文档配置 R 会话与 MCP，先用示例数据运行一个简单分析。
- 检查：检查实际执行的代码、输入变量和输出，保存软件版本。
- 使用条件与局限：需要 R 和 MCP 环境；自动生成的分析需由使用者审核。

## 完成前检查

- [ ] 原始数据与清洗后数据分别保存
- [ ] 方法与研究设计相符
- [ ] 分析设置和软件版本有记录
- [ ] 关键结果可重现
